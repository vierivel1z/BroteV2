# Controls

Move Suyay: WASD or arrow keys. Interact: E, near the highlighted contextual target.

The nursery gives one seedling per interaction, capacity5. An empty planting spot consumes one seedling. Trees grow automatically:5 seconds to Young, another5 to Developed; each Developed tree adds10 to Salud del Valle. Ten spots reach100.

The upper landscape is decorative and inaccessible. Current MVP uses keyboard input; there is no save/load, pause menu, mouse planting or controller binding implemented.


## Ola2 - current implementation

Ola2 controls: ESC opens pause/continue; F3 debug only Editor/Development. Pause offers confirmed restart, quit and Master/SFX sliders. Restart loses current progress; save/load still absent.
